# SF street sweeping - 19th St by Dolores Park

Static dashboard showing street sweeping days and times for each side of 19th St (Valencia to Castro) plus the four streets around Dolores Park (Dolores, Church, 18th, 20th between the park edges).

Live: GitHub Pages (see the repo's Pages link).

Data: [DataSF Street Sweeping Schedule](https://data.sfgov.org/City-Infrastructure/Street-Sweeping-Schedule/yhqp-riqs), snapshot pulled Sep 24, 2026. The schedule is baked into `index.html`; "next sweep" and "today" are computed in the browser in Pacific time.

Posted signs always win.
